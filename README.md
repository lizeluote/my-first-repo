# my-first-repo

在 Windows 上用 Git 管理的第一个仓库。

## 记录

- 2026-10-24 初始化仓库，配置 Git、SSH 密钥并接入 GitHub。

## 常用命令

```bash
git status                 # 查看改动
git add .                  # 暂存全部改动
git commit -m "说明"       # 提交
git push                   # 推送到 GitHub
git pull                   # 拉取远程更新
git log --oneline --graph  # 查看历史
```
